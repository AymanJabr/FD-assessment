# About 
This is the Algorithmic task of the Assessment for FlatexDegiro

## Prerequisites

- Node.js installed on your system

## Running the Application

Run the following command in your terminal:

```bash
node index.js
```


## Tests
The test included are:
1) the standard empty array
2) an array where no outgoing from "you" let's to "out"
3) an array, where "you" is the initial device for all of them, and all the outputs are going to end in "out", with several layers in the middle of connections
4) an array with no "you", and another with no "out".
5) A circular test case, where out just also leads to other inputs in the beginning.
6) The input example
7) The actual question that was given to us to solve
